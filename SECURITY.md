# Security policy

Report a security problem in the framework, or a credential that reached the repository, privately:
use **Report a vulnerability** in the repository's **Security** tab, never a public issue. What to
include, and what belongs to the tracker of the API you test instead, is in
[CONTRIBUTING](CONTRIBUTING.md#reporting-a-problem).

The project is before 1.0, so fixes go into the next release; earlier releases are not patched.

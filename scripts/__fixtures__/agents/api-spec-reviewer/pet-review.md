# `Pet review fixtures` test cases

An imaginary feature of the Petstore pack, built on its `pets` client, builders and state models.
Every case creates its own pet and deletes it in a `finally` block, unless its details say
otherwise.

## Case details

### TC-PETREV-01

- **Preconditions**: `default`; a pet body `<PET_ID>` with every field and `<STATUS>`.
- **Request**: `POST /pet`, then `GET /pet/<PET_ID>`.
- **Expected**: `200` `Pet` equal to the sent body; the read-back equals it field by field.
- **Verification**: `expectSameState` against the sent body, for the response and the read-back.
- **Tags**: `@smoke @data-integrity`

### TC-PETREV-02

- **Preconditions**: `default`; a pet `<PET_ID>` created with status `available`.
- **Request**: `PUT /pet` with the stored body, a new `<NAME>` and status `sold`, then
  `GET /pet/<PET_ID>`.
- **Expected**: `200` `Pet`; the read-back holds the new name and the new status.
- **Verification**: follow-up read.
- **Tags**: `@smoke @data-integrity`

### TC-PETREV-03

- **Preconditions**: `default`; a pet `<PET_ID>` created with every field.
- **Request**: `PUT /pet` with the stored body and `name` removed.
- **Expected**: `400` `input-error` (or `422` with an `ApiResponse` body); the pet unchanged.
- **Verification**: state comparison of the read-back with the state before the write.
- **Departure**: GAP-1: `200`, and the pet is stored without `name`.
- **Tags**: `@regression @contract-drift @data-integrity @known-gap`

### TC-PETREV-04

- **Preconditions**: `default`; a pet `<PET_ID>` created with a status other than `available`.
- **Request**: `PUT /pet` with the stored body, a new `<NAME>` and `status` removed.
- **Expected**: `200` `Pet`; only `name` changes, the status is kept.
- **Verification**: `expectOnlyChanged(before, after, PET_FIELDS, ['name'])`.
- **Tags**: `@regression @data-integrity`

### TC-PETREV-05

- **Preconditions**: `default`; a pet `<PET_ID>` created by the case.
- **Request**: `PUT /pet` with the stored body, a new `<NAME>` and `tags` removed.
- **Expected**: `200` `Pet`; the stored tags are kept.
- **Verification**: follow-up read.
- **Tags**: `@regression @data-integrity`

### TC-PETREV-06

- **Preconditions**: `default`; `<UNKNOWN_PET_ID>`.
- **Request**: `GET /pet/<UNKNOWN_PET_ID>`.
- **Expected**: `404` `not-found`.
- **Verification**: response only.
- **Tags**: `@regression`

### TC-PETREV-07

- **Preconditions**: `default`; a pet `<PET_ID>` created with `<STATUS>`.
- **Request**: `GET /pet/findByStatus?status=<STATUS>`.
- **Expected**: `200`; the list holds `<PET_ID>`, matching `Pet`, and every listed pet has
  `<STATUS>`. Other callers' pets are checked for their status only.
- **Verification**: response only.
- **Tags**: `@regression`

### TC-PETREV-08

- **Preconditions**: `default`; none.
- **Request**: `GET /pet/findByStatus?status=sold`.
- **Expected**: `200` and a list whose items match `Pet`.
- **Verification**: response only.
- **Tags**: `@sanity`

### TC-PETREV-09

- **Preconditions**: `default`; a full pet body with `<UNKNOWN_PET_ID>`.
- **Request**: `PUT /pet`, then `GET /pet/<UNKNOWN_PET_ID>`.
- **Expected**: `404` `not-found`; no pet is created.
- **Verification**: the read answers `404`.
- **Cleanup**: if the read shows a pet, delete it.
- **Tags**: `@regression @data-integrity`

### TC-PETREV-10

- **Preconditions**: `default`; a pet `<PET_ID>` created by the case.
- **Request**: `DELETE /pet/<PET_ID>` twice.
- **Expected**: `200`, then `404` `not-found`.
- **Verification**: response only.
- **Tags**: `@regression`

### TC-PETREV-11

- **Preconditions**: `default`; a pet `<PET_ID>` created by the case.
- **Request**: `DELETE /pet/<PET_ID>`, then `GET /pet/<PET_ID>`.
- **Expected**: `200`, then `404` `not-found`.
- **Verification**: follow-up read.
- **Tags**: `@smoke @data-integrity`

### TC-PETREV-12

- **Preconditions**: `default`; one pet body per member of `Pet.status`.
- **Request**: `POST /pet` per body, then `GET /pet/<PET_ID>`.
- **Expected**: `200` each; the read-back matches `Pet` and holds the status sent.
- **Verification**: follow-up read per member.
- **Tags**: `@regression @data-integrity`

### TC-PETREV-13

- **Preconditions**: `default`; a pet `<PET_ID>` created by the case with status `sold`.
- **Request**: `PUT /pet` with the stored body and status `available`, then `GET /pet/<PET_ID>`.
- **Expected**: `200` `Pet`; the read-back holds `available`.
- **Verification**: follow-up read.
- **Tags**: `@regression @data-integrity`
